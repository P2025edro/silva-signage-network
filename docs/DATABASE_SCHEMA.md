# Database schema

PostgreSQL 16. Migrations: `packages/database/migrations/*.sql`, applied by `packages/database/scripts/migrate.sh` (each in a transaction, checksummed; editing an applied migration is refused — add a new one).

## Conventions

- UUID primary keys (`gen_random_uuid()`), except high-volume logs (`bigint` identity).
- `timestamptz` everywhere, stored UTC.
- Soft delete (`deleted_at`) on user-managed records: users, companies, locations, screens, media, campaigns.
- Tenant-owned tables carry `company_id`; the API filters on it in every query.

## Tables

| Group | Table | Purpose / notable constraints |
|---|---|---|
| Identity | `users` | Email lower-case (CHECK), unique among non-deleted. scrypt hash, encrypted TOTP secret, lockout counters. `platform_role` enum. |
| | `sessions` | SHA-256 of cookie token, `mfa_verified`, absolute + idle expiry, revocation. |
| | `user_company_memberships` | `OWNER` / `STAFF`; unique (user, company). *Roles are Postgres enums rather than a `roles` table.* |
| Tenants | `companies` | `is_dev_fixture` flag so fixtures can never pass as customers; `stripe_customer_id` unique. |
| | `business_categories` | Reference list used for targeting and competition rules. |
| Places | `locations` | Opening hours (JSON), time zone, participation flag. CHECK: coordinates only stored when `coordinates_verified`. |
| | `geographic_zones`, `location_zones` | Configurable zones (seeded: Dublin 8, Portobello, Camden Street, Rathmines, Ranelagh, Dublin City Centre, Cabra). |
| | `location_category_rules` | Host competition rules: `ALLOW` / `BLOCK` per category. |
| | `location_advertiser_exclusions` | Specific advertisers a host never shows. |
| Devices | `screens` | Status, reported capabilities, health fields. Trigger: `company_id` must equal the location's company. |
| | `device_pairing_sessions` | HMAC of code, hash of poll secret, status; partial unique index: one live session per code. |
| | `device_credentials` | SHA-256 of bearer token; revocation reason. |
| | `screen_heartbeats` | One row per heartbeat (30-day retention). |
| | `screen_commands` | Unique (screen, idempotency_key); expiry; ack result. |
| Billing | `subscription_plans`, `plan_entitlements` | Prices with `price_is_draft`; entitlements are rows (`max_screens`, `max_active_campaigns`, `max_target_zones`, `monthly_playback_allocation`, `max_campaign_days`, `distribution_weight`, `reporting_level`). |
| | `subscriptions` | `source` = `STRIPE` (mirrored from verified webhooks) or `MANUAL` (pilot/dev; never revenue). Partial unique index: one live subscription per company. CHECK: Stripe rows need a provider id. |
| | `billing_events` | Raw verified provider events; unique (provider, event id) makes webhooks idempotent. |
| Campaigns | `media_assets` | Detected MIME (from file signature), SHA-256, dimensions, duration, codec, storage keys. |
| | `campaigns` | Status enum (11 states), dates (CHECK end > start), priority 1–5, schedule JSON, review fields. |
| | `campaign_reviews` | Every transition with actor, from/to, reason. |
| | `campaign_media`, `campaign_targeting`, `campaign_target_categories`, `campaign_exclusions` | Creatives and targeting. |
| Distribution | `screen_playlists` | Per-screen versions (unique screen+version), checksum, `valid_until`, engine `decisions` JSON. |
| | `playlist_items` | Ordered items with `not_after`. |
| | `delivery_allocations` | Slots per campaign per playlist (capacity reporting). |
| | `playback_events` | `id` generated by the player (idempotent inserts); type `SCHEDULED`/`STARTED`/`COMPLETED`/`FAILED`. |
| Operations | `audit_logs` | **Append-only** (trigger rejects UPDATE/DELETE). |
| | `notifications`, `platform_settings` | Business notices; typed, validated settings. |

## Retention (implemented in the maintenance worker)

| Data | Kept |
|---|---|
| Heartbeats | 30 days |
| Expired/revoked sessions | 30 days |
| Pairing sessions | 7 days |
| Playback events, audit logs, billing events | Indefinitely for now — **set a policy before launch** (see `SECURITY.md`) |

## Commands

```bash
pnpm db:migrate           # DATABASE_URL
pnpm db:migrate:test      # TEST_DATABASE_URL
pnpm test:db              # constraint tests (run in a rolled-back transaction)
```
